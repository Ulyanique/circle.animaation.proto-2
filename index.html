ФОТО И ВИДЕО

Замените материалы в десяти сценах. Пропорции сохраняются целиком. Видео воспроизводятся без звука. Выберите готовый фрагмент (с начала) или полную запись (по таймкоду). Кнопка «Смотреть сцену» откроет её на паузе. Для каждой нарезки задан исходный таймкод; точный конец указан только для Шульган.

Файлы остаются в браузере и не загружаются на сервер. После обновления страницы восстановятся исходные материалы.
